## How to use

1. Launch the freshly packaged local `build/Academic Markdown.app`.
2. Open Theme Studio from the app's existing theme menu.
3. Choose Classic/Compact on Home or enter Builder and add a Section/Cover.
4. Select a child on the canvas or in Layers and edit Content/Style.
5. For reusable title/author text, choose a Dynamic metadata source; literal
   content remains the fallback.
6. Use Compiled PDF to check the real offline output. Failed builds retain the
   last valid PDF but label it stale; use Recompile PDF to retry.
7. Save Theme, reopen it from Theme Library, and explicitly Apply to another
   report. Existing report content and unrelated metadata remain intact.
8. Report structure still uses its explicit Markdown/LMX structure markers;
   applying a style does not silently insert a cover into a report.
