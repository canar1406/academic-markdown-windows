These companions supplement the regular lmmono10 font already in the reduced
TTB. Native compilation copies only these fixed filenames into its isolated
workspace. No system font installation, online runtime fetch or document-driven
font path execution is required. This does not change the theme's default body
font or silently remove bold/italic formatting from inline code.
